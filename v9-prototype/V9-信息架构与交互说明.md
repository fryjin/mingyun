# 今晚谁遭殃 V9：信息架构与交互原型说明

> 本版本仅用于确认产品结构、UI 方向和关键交互。未迁移 V8 的游戏逻辑与 3500 道扩容题库数据包。

## 1. 本轮确认范围

### 保留玩法
1. 命运骰局
2. 命运转盘

### 新增玩法
3. 谁最可能
4. 二选一
5. 五秒挑战（默认 5 秒，支持 3–60 秒自由设置）
6. 炸弹传递
7. 谁是卧底
8. 国王游戏

## 2. 顶层信息架构

```text
应用
├── 游戏大厅
│   ├── 当前派对房间
│   ├── 本场推荐
│   ├── 游戏分类
│   ├── 游戏卡片宫格
│   └── 游戏详情抽屉
├── 玩家管理
│   ├── 人数 2–12
│   ├── 自定义名称
│   ├── 玩家顺序
│   ├── 随机昵称
│   └── 本场保存
├── 游戏舞台（下一阶段迁移）
│   ├── 随机类舞台
│   ├── 投票类舞台
│   ├── 挑战类舞台
│   └── 推理类舞台
└── 全局设置
    ├── 音效
    ├── 震动
    ├── 默认题目尺度
    ├── 成人档确认
    └── PWA / 缓存更新
```

## 3. 首页游戏大厅

### 信息层级
1. 品牌与全局设置
2. 当前派对房间摘要
3. 本场推荐玩法
4. 分类筛选
5. 两列游戏卡片
6. 底部导航

### 游戏卡片只展示
- 游戏名称
- 一句话玩法
- 适合人数
- 玩法类别
- 是否支持成人档

详细规则和专属设置全部放入底部抽屉，避免首页卡片过重。

## 4. 派对房间与玩家管理

玩家名单从具体游戏设置中抽离，成为全局共享状态。

### 管理能力
- 支持 2–12 人任意整数，包括 3、5、7、9、11
- 自定义玩家名称
- 随机昵称
- 调整玩家顺序
- 后续可扩展临时停用玩家

所有游戏进入前读取同一份玩家名单。

## 5. 游戏详情抽屉

点击游戏卡片后先打开底部抽屉，不立即进入游戏。

抽屉包括：
- 玩法名称与图标
- 适合人数、单局时长
- 简洁玩法说明
- 手机使用方式
- 结果与胜负方式
- 该游戏独有设置
- 开始游戏主按钮

## 6. 八种玩法设置范围

| 游戏 | 专属设置 |
|---|---|
| 命运骰局 | 最大/最小点数输、惩罚尺度 |
| 命运转盘 | 转动节奏、惩罚尺度 |
| 谁最可能 | 并列规则、题目尺度 |
| 二选一 | 少数派/多数派/解释模式、题目尺度 |
| 五秒挑战 | 3–60 秒自由时长、预设 5/10/15/30 秒、题目尺度 |
| 炸弹传递 | 隐藏引爆区间、传递方向、题目尺度 |
| 谁是卧底 | 卧底人数、空白牌、回合上限、词库难度 |
| 国王游戏 | 指令来源、尺度、跳过规则 |

## 7. 视觉方向

- 保留深色夜场基调，但减少大面积玻璃拟态和无意义光效。
- 紫粉作为品牌色，不再作为所有玩法的唯一识别色。
- 不同玩法拥有独立识别色和图形符号。
- 首页使用推荐大卡 + 两列宫格，提升多玩法浏览效率。
- Emoji 更换为统一 SVG 图标，降低不同系统的视觉差异。

## 8. 下一阶段迁移顺序

在确认本原型后：

1. 建立游戏注册表和全局派对房间状态。
2. 迁移骰子与命运转盘到新架构。
3. 实现谁最可能、二选一、五秒挑战、炸弹传递。
4. 实现谁是卧底和国王游戏的多阶段状态机。
5. 将普通题库与 2000 道成人题库拆包并按需加载。
6. 更新 Service Worker、缓存版本和离线资源策略。
