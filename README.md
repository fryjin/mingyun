# V9.2.1 首页顶部栏热修复

## 修复问题

移动端首页偶发出现顶部区域异常增高、品牌区域被挤成竖条、设置按钮漂移的问题。

## 根因

首页隐藏返回按钮后，`app-header` 的 CSS Grid 自动补位，导致品牌按钮进入左侧窄列；品牌副标题被连续换行后把 Header 撑高。旧 Service Worker 缓存可能继续组合旧、新样式，使问题呈现为偶发。

## 修复内容

- 返回、品牌、设置按钮固定到明确的三列网格位置
- 品牌按钮增加宽度、最小宽度和固定高度约束
- 标题、副标题强制单行省略，不再纵向换行
- 品牌 SVG 增加固定尺寸和溢出约束
- 主题样式增加 `v=9.2.1` 缓存版本参数
- Service Worker 缓存版本升级为 `party-game-v9.2.1`

## 覆盖文件

- `index.html`
- `sw.js`
- `styles/midnight-game-hall.css`

覆盖后重新部署。首次打开若仍显示旧页面，请刷新一次；PWA 用户可关闭页面后重新打开。
