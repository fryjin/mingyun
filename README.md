# 今晚谁遭殃 V9.1.4

移动端优先、单部手机多人共玩的派对游戏 PWA。本版完成第二轮 UI/交互升级，并将“成人进阶”开放到全部 8 种玩法。

## 本版重点

- 大厅、玩家管理、游戏详情抽屉和游戏舞台统一采用 8pt 间距节奏与 44px 触控目标。
- 游戏详情抽屉增加固定底部开始按钮，长设置页面无需滚回底部。
- 五档内容尺度改为卡片式选择，360px 屏幕不再拥挤。
- 弹层增加显式关闭按钮、焦点锁定、Esc 关闭和关闭后焦点恢复。
- 玩家暂离状态、按钮反馈、选中状态和键盘焦点更加清晰。
- 成人进阶开放到全部游戏；新增 2000 条专用内容。
- 炸弹传递时长调整为：短局 10–20 秒、中局 20–40 秒、长局 40–60 秒。

## 部署

本包为累计升级包，可覆盖 V9.1.2、V9.1.2.1 或 V9.1.3。解压后将全部文件按原路径覆盖到仓库根目录，不要删除包内未包含的旧题库文件。

部署后若仍显示旧版，刷新两次；仍未更新时清除站点缓存和旧 Service Worker。

## 自动校验

完整仓库覆盖后执行：

```bash
python scripts/validate_project.py
```

仅检查升级包可执行：

```bash
python scripts/validate_v9_1_4_patch.py
```
