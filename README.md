## V9.3 国王游戏

### 身份与号码

- 每轮重新洗牌。
- 一位玩家获得“国王”身份。
- 其他玩家分别获得唯一秘密号码。
- 玩家轮流传递手机查看身份。
- 每次查看前都有独立交接屏，避免上一位身份残留。
- 身份展示期间切到后台，会自动重新隐藏。

### 随机题库模式

- 国王从当前内容尺度中随机抽取指令。
- 指令自动决定需要 1 位或 2 位号码玩家。
- 系统随机抽取对应号码。
- 国王可换题，再揭晓号码对应的真实玩家。

### 国王自定模式

- 国王可选择 1 位或 2 位目标玩家。
- 系统随机抽取号码，避免国王直接点名。
- 可输入最多 80 字的自定义指令，也可留空后口头发布。
- 页面持续显示安全边界和跳过规则。

### 自愿与安全

- 任意玩家都可以跳过、换题或改成无接触版本。
- 成人档仅在会话内完成 18+ 与自愿确认后开启。
- 题库不包含危险行为、强制饮酒、公开隐私、羞辱或未经同意的身体接触。

## PWA 缓存

- Service Worker 缓存版本升级为 `mingyun-v9.3-*`。
- `king.js` 加入应用壳预缓存。
- 国王游戏的具体指令 JSON 继续按需加载并运行时缓存。
- 成人题库不进入首屏预缓存。

## 本地运行

```bash
python -m http.server 8080
```

访问 `http://localhost:8080`。ES Module、JSON 题库和 Service Worker 需要通过 HTTP/HTTPS 测试。
