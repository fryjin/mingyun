# 今晚谁遭殃 V9.1.1

移动端优先、单手机多人共玩的派对游戏 PWA。本补丁在 V9.1 模块化架构上进一步收敛玩法规则、修复信息展示，并恢复骰子与转盘的轻量动画质感。

## 本次体验修正

1. **二选一**：结算规则只保留“少数派”和“多数派”。
2. **国王游戏**：每轮仍重新分配号码和国王；抽签号码与任务改为一次性同屏揭晓。
3. **命运骰局／命运转盘**：增加统一轻量动画层。DOM 微动效优先采用 Anime.js WAAPI 模块；离线或模块尚未加载时立即使用原生 WAAPI；转盘主体继续使用 RAF 处理连续物理转动。
4. **谁是卧底**：发言时限五个选项固定单行；私密页面只显示词，不显示身份；500 组词库已重新审校并替换机械拼接词。
5. **炸弹传递**：只保留顺时针和逆时针；运行时不显示具体持有者，也不要求点击“传给下一位”；应用只处理隐藏计时和爆炸反馈。

## 游戏模式

1. 二选一：逐人私密选择，全部完成后统一揭晓。
2. 国王游戏：每轮重新洗牌、重新查看号码、重新抽取国王，并同屏揭晓任务与执行号码。
3. 命运骰局：玩家依次投掷 3D 骰子，按最高点或最低点判定输家。
4. 命运转盘：使用 RAF 驱动转动过程，配合轻量指针和结果反馈。
5. 谁是卧底：私密看词、限时描述、秘密投票和阵营胜负。
6. 谁最可能：无主持人、逐人秘密投票、统一揭晓。
7. 五秒挑战：支持 3–60 秒自由倒计时。
8. 炸弹传递：隐藏倒计时，到点显示爆炸动画。

## 工程结构

```text
index.html
├── src/main.js
├── src/core/                 状态、工具、本地存储与轻量动画层
├── src/modules/              大厅、玩家、抽屉、设置、题库加载器
├── src/games/                游戏注册表、共享结果和 8 个游戏插件
├── styles/                   全局与游戏舞台样式
├── data/questions/           3500 道共享惩罚题库
├── data/games/               2500 条／组专用内容
├── scripts/validate_project.py
├── manifest.webmanifest
└── sw.js
```

应用主体继续使用原生 ES Module，不引入 React 或 Vue。Anime.js WAAPI 模块按需加载；网络不可用时不会阻塞游戏动画。

## 本地运行

Service Worker、ES Module 和题库请求需要 HTTP/HTTPS：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。

## GitHub Pages

将本目录内容上传到仓库根目录，然后在 GitHub Pages 中选择：

```text
Deploy from a branch → main → /root
```

部署后若仍显示旧版，可刷新两次；仍未更新时清除该站点缓存和旧 Service Worker。

## 自动校验

```bash
python scripts/validate_project.py
```

校验内容包括：

- 共享题库 3500 条
- 专用内容 2500 条／组
- 所有 JSON 数量与字段
- 所有 ID 唯一
- 规范化正文、选项和词组去重
- V9.1.1 五项交互回归规则
