# V9.2.2 逻辑锁定修复包

本修复包的唯一目标：**保留 V9.1.4 已确认游戏逻辑，只升级 Midnight Game Hall UI。**

## 已锁定的游戏流程

- 谁最可能：逐人秘密投票，全部完成后统一揭晓。
- 二选一：逐人私密选择 A/B，全部完成后统一揭晓。
- 炸弹传递：隐藏随机倒计时，按固定方向传手机；不增加传递任务、持有者轮换按钮或传递次数记录。
- 谁是卧底：私密查看短词，不额外显示身份标签。
- 其余游戏、题库加载、成人进阶边界、惩罚抽取与结算沿用 V9.1.4。

## UI 保留范围

- Midnight Game Hall 主题 CSS
- 顶部品牌徽章和顶部栏布局热修复
- SVG 装饰素材
- 暗夜卡片、抽屉、按钮和舞台视觉

## 缓存修复

本版增加一次性旧缓存清理，并将 Service Worker 改为源码资源 network-first，避免旧游戏脚本与新 UI 混用。
