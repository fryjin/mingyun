# 今晚谁遭殃 V9.1

移动端优先、单手机多人共玩的派对游戏 PWA。V9.1 完成从单文件 UX 原型到正式模块化应用的迁移，并接入 8 种可玩模式、3500 道共享惩罚题库和 2500 条／组专用内容。

## 游戏模式

1. 二选一：逐人私密选择，全部完成后统一揭晓。
2. 国王游戏：每轮重新洗牌、重新查看号码、重新抽取国王与执行号码。
3. 命运骰局：玩家依次投骰，按最高点或最低点判定输家。
4. 命运转盘：使用 RAF 驱动的随机转盘。
5. 谁是卧底：私密看词、限时发言、秘密投票和阵营胜负。
6. 谁最可能：无主持人、逐人秘密投票、统一揭晓。
7. 五秒挑战：支持 3–60 秒自由倒计时。
8. 炸弹传递：隐藏随机倒计时的纯传递玩法。

## 内容规模

| 内容 | 数量 |
|---|---:|
| 共享真心话／大冒险 | 3500 |
| 谁最可能 | 500 |
| 二选一 | 500 |
| 五秒挑战 | 500 |
| 国王游戏 | 500 |

成人内容只在会话级 18+ 自愿确认后加载。所有涉及其他玩家的互动均可跳过，并要求相关玩家明确同意。

## 工程结构

```text
index.html
├── src/main.js
├── src/core/                 状态、工具与本地存储
├── src/modules/              大厅、玩家、抽屉、设置、题库加载器
├── src/games/                游戏注册表、共享结果和 8 个游戏插件
├── styles/                   全局与游戏舞台样式
├── data/questions/           3500 道共享惩罚题库
├── data/games/               2500 条／组专用内容
├── scripts/validate_project.py
├── manifest.webmanifest
└── sw.js
```

不依赖 React、Vue 或第三方运行时，全部使用原生 ES Module。

## 本地运行

Service Worker、ES Module 和题库请求需要 HTTP/HTTPS：

```bash
python -m http.server 8080
```

打开 `http://localhost:8080`。

## GitHub Pages

将本目录内容上传到仓库根目录，然后在 GitHub Pages 中选择：

```text
Deploy from a branch → main → /root
```

部署后若仍显示旧版，可刷新两次；仍未更新时清除该站点缓存和 Service Worker。

## 自动校验

```bash
python scripts/validate_project.py
```

校验内容包括：

- 共享题库 3500 条
- 专用内容 2500 条／组
- 所有 JSON 数量与字段
- 所有 ID 唯一
- 规范化正文／选项／词组去重
- 关键工程文件存在
- Service Worker 缓存版本
