本数据包为 V9 正式迁移前的共享惩罚题库，不改变当前高保真 UI 原型的游戏逻辑。

## 文件结构

- `data/questions/manifest.json`：题库清单、计数、文件摘要与加载策略。
- `data/questions/*.json`：按档位和题型拆分的 8 个数据包。
- `题库索引.csv`：便于运营、产品和内容人员筛选审校。
- `validation-report.json`：自动校验结果。
- `scripts/validate_questions.py`：可重复执行的校验脚本。

## V9 迁移建议

1. 首屏不加载任何完整题库。
2. 玩家选择档位后，仅加载对应档位与题型的 JSON。
3. 成人档在完成 18+ 与自愿确认后再请求。
4. 已使用数据包可交给 Service Worker 运行时缓存。
5. “谁最可能、二选一、五秒挑战、炸弹传递、谁是卧底、国王游戏”应建立各自的专用题库，不直接复用本包作为主内容。

## 成人档边界

- 仅限所有参与者均已满 18 岁。
- 所有玩家均明确、自愿开启。
- 互动任务涉及其他玩家时必须再次征得同意。
- 任意玩家可随时跳过、暂停或更换题目。
- 不包含强制饮酒、脱衣、危险行为、公开私密信息或未经同意的身体接触。
