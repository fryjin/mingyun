## V9.4 谁是卧底

### 游戏设置

- 4–12 位在场玩家。
- 根据参与人数自动限制 1–3 位卧底，避免阵营失衡。
- 可选空白牌；开启后其中一位卧底不显示词语，隐藏阵营总人数不变。
- 词库难度：轻松、标准、烧脑。
- 可开启或关闭“最后一位卧底猜词翻盘”。

### 完整牌局流程

1. 系统按当前设置加载一组平民词与卧底词。
2. 玩家逐个接过手机，秘密查看自己的词语。
3. 首位发言玩家随机产生，所有存活玩家轮流描述。
4. 每位存活玩家依次秘密投票，不能投给自己。
5. 平票时只对平票玩家加赛；再次平票由系统随机决胜。
6. 淘汰后显示玩家身份，并自动判断阵营胜负。
7. 若最后一位隐藏阵营玩家被淘汰且开启翻盘，可猜一次平民词。
8. 牌局结束后揭晓词语和全部玩家身份，可换词重开。

### 隐私保护

- 查看词语前使用独立交接页。
- 投票前使用独立交接页。
- 词语或投票页面切到后台时会自动重新隐藏。
- 不在大厅或详情抽屉中预加载完整词库。
