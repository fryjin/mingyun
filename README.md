# 今晚谁遭殃 V9.1.3

移动端优先、单部手机多人共玩的派对游戏 PWA。本版新增第五档 **成人进阶**，仅用于共享惩罚与国王指令。

## 新增内容

- 成人进阶真心话：500 道
- 成人进阶大冒险：500 道
- 成人进阶国王指令：1000 条
- 新增合计：2000 条
- 全项目启用内容：8000 条／组

## 成人进阶边界设置

成人进阶可单独控制：

- 身体接触：关闭／开启
- 接触程度：轻接触／亲密互动
- 亲吻互动：默认关闭，仅包括额头、脸颊或手背
- 酒水互动：默认关闭，只允许“一小口”，始终支持无酒精替代

成人进阶只在命运骰局、命运转盘和国王游戏中显示。其他专用玩法仍使用原有四档内容，避免请求不存在的专用题库。

## 同意机制

- 首次进入成人进阶时进行会话级成年与自愿确认。
- 涉及接触、亲吻或双人互动的题目，在内容揭晓后再次确认。
- 任意玩家可以拒绝、换题、使用无接触／无酒精替代方案或中途停止。
- 拒绝不会产生追加惩罚。
- 不包含脱衣、私密部位接触、限制呼吸、疼痛、强制饮酒或必须喝完一杯等内容。

## 部署

本包为 V9.1.2／V9.1.2.1 的累计升级包。解压后将包内文件按原路径覆盖到仓库根目录，不要删除未包含的旧题库和工程文件。

部署后刷新两次；仍显示旧版本时清除站点缓存或注销旧 Service Worker。
