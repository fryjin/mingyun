# V9.1.4 UI/UX 决策

## 使用场景

- 多人围坐或站立，一部手机在玩家之间传递。
- 环境可能较暗、嘈杂，用户注意力不持续停留在屏幕上。
- 操作常由单手完成，并可能在喝饮品、聊天或计时中进行。
- 私密选择和看词页面需要防止上一位内容残留。

## 主要调整

### 大厅

- 派对房间显示为状态摘要，减少重复说明。
- 游戏卡片保留两列，但增加清晰序号和底部元信息。
- 成人进阶使用轻量标识，不抢占游戏名称层级。

### 游戏详情抽屉

- 内容区独立滚动，开始按钮固定在底部安全区。
- 五档尺度改成两列卡片，成人进阶占整行。
- 每个档位同时展示名称和一句解释，降低误选。
- 成人进阶边界只在选择该档时展开。

### 玩家管理

- 暂离和恢复增加状态点及文字，不只改变透明度。
- 保存前校验至少两名在场玩家。
- 人数和暂离按钮增加 ARIA 状态。

### 弹层

- 增加明确关闭按钮。
- 打开后焦点进入弹层，Tab 不会离开弹层。
- Esc 可关闭普通弹层，关闭后返回原触发控件。

### 游戏舞台

- 顶部游戏标题在滚动时保持可见。
- 主按钮、选择按钮和私密操作均满足触控尺寸。
- 小屏下操作按钮自动改为单列，避免文字挤压。

## 成人进阶

- 全部游戏都能选择成人进阶。
- 有专用内容的玩法按边界设置过滤专用题库。
- 炸弹、骰子和转盘通过共享惩罚接入成人进阶。
- 五秒挑战在含接触、亲吻或酒水时，倒计时前进行逐题确认。
