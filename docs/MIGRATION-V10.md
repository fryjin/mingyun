# V10 迁移计划

## V10.0 基础层

- Application 与 GameRuntime 接管入口
- 注册中心支持 V9/V10 双轨
- 建立 engine、data-engine、components、motion 分层
- 迁移命运骰局、谁最可能
- 增加 Vite、测试和 Pages 构建流程

## V10.1 简单游戏

- 命运转盘
- 二选一
- 五秒挑战

## V10.2 状态型游戏

- 我居然做过
- 两个真相一个谎言
- 混乱法则

## V10.3 重型游戏

- 命运叠塔
- 炸弹传递
- 谁是卧底
- 国王游戏

## 迁移规则

1. 游戏 ID、设置字段和用户可见规则保持兼容。
2. 每次只迁移少量游戏，部署后完成真实手机回归。
3. 题库内容不随架构迁移重写。
4. 旧插件在对应 V10 插件稳定前不删除。
5. 所有新插件必须使用生命周期清理和统一服务。
