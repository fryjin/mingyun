## V10.3 状态复杂型

### 两个真相一个谎言

- 使用 `StateMachine` 约束讲述、私密投票、锁定答案、逐条揭秘和即时惩罚。
- 使用统一随机服务生成讲述顺序。
- 使用 `TurnManager` 管理讲述者和投票者。
- 私密页面切后台立即退回交接页。
- 保持“全员猜对则讲述者受罚；有人猜错则讲述者线下指定猜错者”的现有规则。

### 谁是卧底

- 使用 `StateMachine` 约束看词、发言、投票、结算。
- 使用统一随机服务分配卧底和处理最高票平局。
- 使用 `TurnManager` 管理看词、发言和秘密投票。
- 使用 `TimerController` 管理发言时限。
- 私密看词、私密投票切后台时退回交接页；发言计时切后台时暂停并在返回后继续。

### 混乱法则

- 新增 `ChaosSession` 管理失误、个人权利、持续法则和回合。
- 个人权利仍仅保留：护盾、废除法则、转移挑战。
- 使用 `TimerController` 管理个人挑战倒计时。
- 使用 `QuestionEngine.poolKeySuffix` 按挑战秒数隔离抽取池。
- 题库内容、成人边界、失误上限、权利上限和持续法则上限保持不变。

## 迁移规则

1. 游戏 ID、设置字段和用户可见规则保持兼容。
2. 题库内容不随架构迁移重写。
3. 迁移后先保留旧文件用于回滚，但不再进入运行入口。
4. 私密信息必须接入页面可见性保护。
5. 计时器、事件和动画必须进入统一生命周期。
6. 状态复杂游戏必须明确区分阶段状态与业务数据状态。
