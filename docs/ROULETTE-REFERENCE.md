# 命运转盘设计参考说明

V9.1.2 的赌场轮盘重构参考了开源项目 `IvanAdmaers/react-casino-roulette` 所展示的工程方向：使用纯 HTML、CSS 和 JavaScript 构建轮盘层级，而不是依赖 Canvas 或大型图形引擎。

本项目没有直接引入其 React 包，也没有复制其组件源码。实现仍保持现有原生 ES Module 架构，并根据“玩家姓名扇区随机选择”的产品需求重新设计：

- 赌场绿色台面；
- 木质与金属复合外圈；
- 红黑相间的玩家槽位；
- 独立白球轨道；
- 金色中轴；
- RAF 角速度控制；
- 白球和轮盘反向转动；
- 停止后的玩家结果高亮。

参考项目许可证为 MIT。第三方项目仅作为视觉结构与轻量工程方案的研究参考，不作为本项目运行依赖。
