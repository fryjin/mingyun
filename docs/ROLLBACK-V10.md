# V10.5 回滚策略

## 基线

- V10.5 前稳定基线：`8a802fd2181630d9191a536e6f7cda23ba20d29f`（V10.4）
- V10.5 不改变游戏玩法，只收口工程结构。

## 推荐回滚

如果 V10.5 部署出现构建或资源路径问题，优先整体回滚到 V10.4 基线，而不是单独恢复某个 Legacy 游戏文件。

```bash
git revert <V10.5-commit>
```

或将部署重新指向 V10.4 的已验证构建。

## 不建议

- 不要把 `src/games/fate-ladder.js` 等 Legacy 文件单独恢复到运行入口。
- 不要让 Registry 同时接受 contract v1 / v2。
- 不要混用旧 V9 CSS 文件名与 V10.5 稳定样式名。

## 资源回滚

V10.5 的样式更名不改文件内容。需要回滚时，应连同 `index.html`、`sw.js`、样式文件名一起回滚，避免 Service Worker 缓存旧路径造成 404。
