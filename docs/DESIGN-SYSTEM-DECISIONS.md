# V9.2.3 设计系统决策

## 1. 品牌层级

- 大厅承担完整品牌展示。
- 游戏过程优先显示游戏名、当前状态和主要操作。
- 品牌只提供归属感，不重复占据游戏首屏。

## 2. 装饰预算

每个页面最多保留一个主要氛围母题：

- 大厅房间卡：拱形舞台。
- 游戏卡：顶部细线和图标色。
- 游戏舞台：不再叠加拱门、角饰和星空。
- 工具页面：不使用装饰背景。

## 3. 色彩角色

| 角色 | 颜色 |
|---|---|
| 品牌主操作 | 暗金 |
| 主要文字 | 象牙白 |
| 次要文字 | 冷灰紫 |
| 危险、惩罚、成人 | 酒红 |
| 成功 | 低饱和绿 |
| 游戏色 | 仅用于图标、细线和局部状态 |

## 4. 游戏差异化

- 谁最可能：投票和揭晓。
- 二选一：蓝、琥珀双阵营。
- 五秒挑战：品牌金色倒计时。
- 炸弹传递：酒红危险语义。
- 谁是卧底：私密、遮蔽、短词。
- 国王游戏：号码和指令。
- 骰局：实体骰子与结果数字。
- 转盘：轮盘机械结构。

差异由玩法结构承担，不再依赖每个游戏一套高饱和主按钮。
