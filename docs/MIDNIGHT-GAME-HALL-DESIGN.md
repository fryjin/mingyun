# Midnight Game Hall 设计说明

## 设计目标

把当前产品从“功能型派对小游戏网页”升级为一个更完整的夜间派对游戏空间。

## 视觉策略

### 1. 品牌空间
- 深午夜蓝与黑色作为背景基底
- 金色、象牙白作为文本与高亮
- 酒红与紫色只作为局部氛围光，不大面积铺满

### 2. 游戏房间
- 大厅中的每个卡片不再只是功能入口，而是一个“房间”
- 通过房间名、装饰角、微光晕和图标来建立识别

### 3. 可复用素材
- 徽章、拱门、分隔饰条、角饰与星点纹理都为可独立复用的 SVG
- 这些素材后续可继续用于更多游戏页、封面图与活动页

### 4. 舞台感
- 进入游戏后，标题区和内容卡统一切换成更沉浸的“舞台”空间
- 不通过复杂 3D，而通过层级、阴影、光晕和纹理加强沉浸感
