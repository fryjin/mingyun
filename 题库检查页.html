总计 3500 道：1750 道真心话 + 1750 道大冒险。以下仅展示代表性样例。

轻松 · 真心话

  1. 今天发生过最让你开心的一件小事是什么？
  2. 你最想立刻学会的一项技能是什么？
  3. 你希望别人记住你的哪一种耐心？
  4. 如果今天可以暂停所有责任去练习旅行方式，你会怎么安排？
  5. 过去一年里，哪一次突然放假的一天最让你开心？

轻松 · 大冒险

  1. 用三种不同情绪说一遍自己的名字。
  2. 模仿一种动物，直到有人猜中。
  3. 用舞台主持人语气在十秒内说出三种周末活动。
  4. 用游戏主播的方式向大家推荐周末活动。
  5. 闭眼两秒后，摆出一个“准备出发旅行”的表情。

标准 · 真心话

  1. 你最近一次假装没事，其实心里很在意的事情是什么？
  2. 你曾经对一个人的第一印象错得有多离谱？
  3. 你认为冒险和确定性哪一个更难长期维持？为什么？
  4. 关于道歉，你认为关系里最公平的处理方式是什么？
  5. 你最想改善自己处理保持专注的哪一种方式？

标准 · 大冒险

  1. 选择一位玩家，与对方进行十五秒不笑对视。
  2. 让大家给你三个关键词，并立即编成一句自我介绍。
  3. 在二十秒内解释“为什么要道歉”，但不能使用“朋友”这个词。
  4. 用二十秒讲一个关于网络社交的即兴故事，必须出现“耳机”。
  5. 用一句不超过十个字的话回答：“怎样判断朋友是否真诚？”

大胆 · 真心话

  1. 现场谁最接近你的理想型？可以只说特质。
  2. 你有没有喜欢过一个不该喜欢的人？
  3. 你有没有把依赖误认为爱情或喜欢？后来怎样发现的？
  4. 你认为缺少信任的关系还能维持多久？
  5. 重要的人做出“公开你的秘密”时，你会把它视为背叛吗？

大胆 · 大冒险

  1. 选择一位玩家，用三十秒认真说明你欣赏对方的地方。
  2. 与一位自愿参加的玩家完成二十秒默契动作同步。
  3. 用二十秒演出“误会终于解开”，但不能说出事件名称。
  4. 围绕“想复合但不敢说”做一次十五秒立场陈述，并说出你的底线。
  5. 请一位自愿玩家与你完成“分开后偶遇”的十秒无接触对话。

成人刺激 18+ · 真心话

  1. 你最容易被一个人的哪种身体或气质特征吸引？
  2. 你对一夜情的真实看法是什么？
  3. “深夜城市散步”对你来说更浪漫、刺激还是有压力？
  4. 如果伴侣提出“长期异地”，你最先想确认什么？
  5. 发生分手时，关于浏览记录最成熟的处理方式是什么？

成人刺激 18+ · 大冒险

  1. 选择一位明确自愿的玩家，保持十五秒近距离对视，不需要身体接触。
  2. 对一位明确自愿的玩家，用耳语语气说一句暧昧但尊重的称赞。
  3. 用餐巾纸和充电线摆出一张成人爱情电影海报。
  4. 为虚构情侣的“决定分手前的最后谈话”安排一个尊重边界的无酒精饮品。
  5. 用电台主播语气读出一条关于“如何保持长期吸引力”的安全提醒。
